WDwdataDeribit(optopt) → {Object}

Description:

  • 建立Deribit公開行情之下載器(不需金鑰，只送公開之查詢參數)：選擇權逐筆成交之每日檔、彙整為格與每日基本量、隱含波動指數。 同一下載器之並行呼叫共用同一個節流(相鄰兩次請求之起始至少相隔opt.minGapMs)，故可同時對不同日期範圍呼叫saveTrades。

    選項檢測：決定下載來源與網路出口者(hostHistory、hostLive、proxy)給了而無效即拋(訊息為'invalid opt.<名稱>: must be <種類>'，不帶輸入值)，不改用預設； 其餘為執行參數(minGapMs、retryTimes、timeRetry、timeRetryMax、timeRequest)，undefined與null視為未給(用預設)，給了而無效改用預設，不拋錯，opt.debug為true時另輸出警告(不含輸入值)，整數類接受數字字串並轉為數值。

Example
import WDwdataDeribit from 'w-dwdata-deribit'

async function test() {

    //wdd
    let wdd = WDwdataDeribit()

    //下載ETH選擇權之逐筆成交至每日檔(UTC日, 已有檔之日不重抓)
    let r = await wdd.saveTrades('ETH', 'option', './data/ETH/option', '2024-02-29', { dayEnd: '2024-03-01' })
    console.log(r.saved.map((v) => [v.day, v.n]))

    //以使用端之日界(台北2024-03-01 = [02-29T16:00Z, 03-01T16:00Z))取用: 讀檔 → 格 → 基本量
    let tStart = Date.parse('2024-02-29T16:00:00Z')
    let s = wdd.summarizeRange('./data/ETH/option', tStart, tStart + 86400000)
    console.log(s.complete, s.n, s.summary.pcr)

}

(async) saveTrades(client, host, currency, kind, fdTrades, dayStart, optopt) → {Promise}

Description:

  • 逐日(UTC日)下載並存檔；已有檔之日不重抓(不送請求)；只處理已結束且過了寬限之日(日終 + opt.timeGrace不晚於現在)。 請求失敗之日不寫檔(下次執行再抓，不標註為無數據；依時間查成交時「空」是有效之回答，0筆之日照樣寫出只有欄名之檔)。 停止本次執行之後續請求：交易所維護(503)或流量限制用盡重試；連續opt.netFailTimes日皆為連線層失敗(連線錯誤、逾時)；未送之日列入failed(kind為'notRequested')。 某日之同一毫秒筆數不小於opt.count而無從分頁者(kind為'pagingLimit')列入failed，不停止本次執行。 必須參數無效時reject(先於任何連網與寫檔)，訊息為'invalid <名稱>: must be <種類>'，不帶輸入值。
